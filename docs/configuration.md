# 配置参考

## 配置文件与优先级

安装器根据示例生成缺失的 `config.toml` 和 `.env`，保留已存在的文件。配置使用 UTF-8 编码，支持 UTF-8 BOM。初始化步骤参见 [快速开始](../README.md#快速开始)。

| 配置来源 | 作用 |
| --- | --- |
| `config.toml` | 账号、发送对象、消息模板、浏览器、调度及通知开关 |
| 配置文件同目录的 `.env` | 代理和通知凭据，以及支持的运行环境参数 |
| Docker 项目根目录的 `.env` | 通过 Compose `env_file` 注入容器进程环境 |
| `--config` | 显式指定配置路径；未指定时读取进程变量 `SPARK_CONFIG`，缺省为当前目录的 `config.toml` |
| `--data` | 显式指定数据目录；未指定时读取 `SPARK_DATA_DIR`，变量未设置或为空时使用配置文件同目录的 `data/` |

进程环境变量优先于配置文件同目录的 `.env`，包括已定义的空值。`SPARK_CONFIG` 在 CLI 参数解析阶段读取，不能仅通过尚未定位的 `.env` 指定。CLI 全局参数位于子命令之前。

`accounts[].proxy` 支持 `${VARIABLE_NAME}` 插值；引用未定义或为空的变量导致配置校验失败。其他 TOML 字符串不执行环境变量插值。

普通 CLI 配置校验失败返回退出码 64；`doctor` 返回诊断失败和退出码 1。GUI/MCP 运行期间的配置错误通过相应接口报告。凭据不得进入版本控制，`.env` 注释独占一行。

## 默认值

下表列出字段省略时的实现默认值。配置示例可能显式设置不同值，例如 `messages.hitokoto = true`。

| 配置项 | 默认值 | 执行语义 |
| --- | --- | --- |
| `general.timezone` | `Asia/Shanghai` | 调度时间和每日账本的时区 |
| `general.keep_days` | `7` | `run` 结束后清理过期运行目录、任务目录及账本 |
| `general.ip_policy` | `exact` | 严格匹配出口 IP；`subnet` 接受同一 IPv4 /24 或 IPv6 /48 网段 |
| `general.save_raw_responses` | `true` | 保存发送接口原始响应 |
| `schedule.enabled` | `false` | 每日调度开关 |
| `schedule.times` | `["12:30", "20:30"]` | 24 小时制 `HH:MM` 执行时间 |
| `timing.jitter_minutes` | `10` | CLI 发送启动及新计划的随机延迟上限；`run --now` 跳过 CLI 启动延迟 |
| `timing.gap_seconds` | `[25, 80]` | 发送对象之间的随机间隔，单位为秒 |
| `timing.typing_delay_ms` | `[60, 170]` | 逐字输入间隔，单位为毫秒 |
| `timing.send_timeout_seconds` | `15` | 会话就绪和发送回执等待阶段的超时，单位为秒 |
| `messages.templates` | 3 条内置消息模板 | 全局候选模板，与示例中的模板值一致 |
| `messages.hitokoto` | `false` | 在线一言请求开关 |
| `notify.enabled` | `true` | 通知推送总开关；发送通知仍要求有效渠道凭据 |
| `mcp.enabled` | `true` | 允许新 MCP 服务启动 |

`keep_days` 不清理账号浏览器用户数据目录。未确认发送结果保护其原始账本及最新后续记录所在账本；运行日志、截图和任务目录继续使用常规保留策略。账本损坏或存在损坏备份时，清理采用保守保留策略。

出口 IP 查询服务由 `general.ip_echo_urls` 指定，按配置顺序尝试。GUI/MCP 服务日志位于 `data/logs/`，按文件大小轮转，单文件上限 1 MB、保留 5 个备份，不受 `keep_days` 控制。

## 账号配置

初始配置不包含账号。控制面板注册成功后登记并启用新账号；取消、超时或失败不登记空账号。显式账号配置示例：

```toml
[[accounts]]
name = "main"
remark = "主账号"
enabled = false
friends = ["好友备注A", "好友备注B", "周末小群"]
proxy = "${MAIN_PROXY}"
templates = ["{date} {weekday}，{friend}"]
```

此示例要求 `.env` 已定义 `MAIN_PROXY`；直接连接使用 `proxy = ""`。

| 字段 | 约束及作用 |
| --- | --- |
| `name` | 固定内部标识，长度 1–32，限定 ASCII 字母、数字、下划线和连字符；拒绝 Windows 保留设备名及仅大小写不同的重复标识 |
| `remark` | 可选显示备注，最长 64 个字符；不修改用户数据目录或历史发送记录 |
| `enabled` | 缺省为 `true`，控制账号是否参与发送；与每日调度开关独立 |
| `friends` | 显式发送对象列表，支持唯一的好友备注名、昵称及完整群聊名称 |
| `proxy` | 网络代理配置；推荐使用环境变量引用 |
| `templates` | 账号专用候选模板；空列表表示继承全局模板 |

账号显示名称的优先级为备注、平台本人昵称、内部标识。昵称从平台本人资料响应读取，不使用其他会话标题。

已有账号重新登录保留原启用状态。启用要求存在登录记录，不要求预先执行 `check`；发送前仍进行运行环境和账号身份验证。无发送对象时不提交消息。

### 发送对象与会话匹配

发送对象以 `friends` 为唯一配置依据，不自动扩展列表或扫描其他火花会话。名称匹配规范化部分空白及不可见字符；可见列表中存在多个匹配项时拒绝定位。虚拟滚动列表跨页名称不具备全局唯一性保证，应配置可区分的备注名或群聊名称。

群聊仅确认当前账号的发送回执，不统计其他成员发言。火花天数来自手动会话读取缓存；缓存不可用时 `{days}` 渲染为空字符串。

## 消息模板

每个账号的好友和群聊共用一组候选模板。账号模板为空时继承 `messages.templates`；每次发送随机选择一条模板并渲染当前对象变量。

| 占位符 | 数据来源 |
| --- | --- |
| `{date}` | 配置时区的日期，例如 `10月06日` |
| `{weekday}` | 配置时区的星期名称 |
| `{friend}` | 发送对象名称 |
| `{days}` | 最近一次手动会话读取缓存的火花天数；缺失时为空字符串 |
| `{daily_quote}` | 30 条内置短句，按配置时区日期轮换；同日使用相同短句 |
| `{hitokoto}` | 在线一言内容，或 `hitokoto_fallback` |
| `{source}` | 在线一言来源 |

### 编辑与继承

控制面板每个输入框对应一条完整消息，支持换行、复制、排序、删除和变量插入。上限为 100 条模板，每条 2000 个字符。排序不改变随机选择策略。

「使用全局模板」保存空账号模板列表；单个空白输入框亦可保存为继承配置，多条模板中的空白项要求补充或移除。继承状态下执行编辑或追加操作时，全局模板复制为账号草稿；保存后仅修改当前账号的模板配置。

内置模板分类向账号草稿追加尚未存在的模板，保存后生效；「撤销」操作丢弃未保存修改，将草稿恢复为账号当前配置。快捷模板卡片展示示例，不提供独立的预览对象选择区域。

### 在线内容与预览

`{daily_quote}` 使用内置内容，无网络依赖。`{hitokoto}` 和 `{source}` 要求 `messages.hitokoto = true`；请求失败时使用配置的回退文本。

GUI 后端 `/api/accounts/preview` 支持草稿渲染。内置短句与当日发送一致；在线一言预览使用回退文本，来源为空。MCP 接口不提供模板预览工具。

## 浏览器与登录

| 配置项 | 默认值 | 作用范围 |
| --- | --- | --- |
| `browser.channel` | `chrome` | 系统 Chrome；可选 `msedge` 或 Playwright `chromium` |
| `browser.executable_path` | 未设置 | 浏览器可执行文件路径；支持 `~`，相对路径基于配置目录解析 |
| `browser.offscreen` | `true` | 在支持窗口定位的 Windows/Linux 桌面环境中尝试将有头窗口移至屏幕外 |
| `browser.headless` | `false` | 发送、环境检查和会话读取的无头模式开关 |
| `login.headless` | `true` | 网页登录模式；配置 VNC 密码且未显式设置时为 `false` |
| `login.bind` | `0.0.0.0` | 独立 CLI/MCP 临时登录服务监听地址 |
| `login.port` | `8789` | 独立网页登录服务端口 |
| `login.public_url` | 未设置 | 可访问 URL 前缀；程序追加 `/login/<令牌>` |
| `login.timeout_minutes` | `10` | 登录超时，取值范围 1–60 分钟 |

`browser.headless` 和 `login.headless` 独立。窗口、QR 和 VNC 登录模式使用有头浏览器；Linux 无图形界面环境要求 Xvfb。显式启用 `login.headless` 时不启动 noVNC。

GUI 登录使用控制面板同源入口和本地随机端口，不使用独立服务的固定监听地址、端口或公网 URL；登录超时和网页登录无头配置仍生效。

## 环境变量

| 变量 | 作用 |
| --- | --- |
| `SPARK_SERVERCHAN_KEY` / `SPARK_PUSHPLUS_TOKEN` | Server酱和 PushPlus 通知凭据，可同时配置 |
| `SPARK_GUI_PASSWORD` | 控制面板首次初始化密码，最少 8 个字符；密码管理参见 [面板认证](usage.md#面板认证) |
| `SPARK_PUBLIC_URL` | 覆盖 `login.public_url`；SSH 本地转发示例为 `http://127.0.0.1:8789` |
| `SPARK_LOGIN_BIND` / `SPARK_LOGIN_HTTP_PORT` | 覆盖独立登录服务的监听地址及端口 |
| `SPARK_VNC_PASSWORD` / `SPARK_VNC_PORT` | noVNC 密码和端口；默认端口 6080，密码最少 6 个字符 |
| `SPARK_ENV` | 值为 `cloud` 时启用云端运行模式；Docker 镜像预设该值 |
| `SPARK_CONFIG` / `SPARK_DATA_DIR` | 配置文件及数据目录路径 |
| `SPARK_GUI_TRUSTED_PROXIES` | Compose 传入 `FORWARDED_ALLOW_IPS` 的可信代理来源地址；禁止通配值 `*` |

### 通知凭据

控制面板「设置」页面将通知凭据写入配置文件同目录的 `.env`，保留其他字段和注释。已保存凭据在输入框中以明文展示，用于查询和编辑；访问该界面要求控制面板认证。

默认配置示例不注入通知变量，面板保存的凭据直接生效。只有通过部署配置管理通知时，才启用根目录 `.env` 中对应的变量定义。

进程中已定义的通知变量优先于 `.env`，包括空值。Docker 项目根目录 `.env` 在容器创建时注入进程，不随文件修改动态刷新。使用控制面板管理渠道时，应移除根目录对应变量定义并重建容器，使 `config/.env` 成为有效来源。操作流程参见 [通知凭据管理](cloud.md#通知凭据管理)。

提交值与进程环境变量不一致时，面板拒绝保存，并保留原凭据及通知开关状态。清除由非空环境变量管理的渠道同样被拒绝；需通过部署配置修改，或切换为面板管理。

通知发送要求总开关启用且渠道已配置。常规通知按标题执行 1 小时去重，失败尝试亦计入记录；测试通知和登录通知不受该去重规则控制。定位验证、无启用对象和全部对象已完成等情况不发送运行摘要通知。

## 代理与状态持久化

网络代理支持 HTTP、HTTPS 和无认证 SOCKS4/SOCKS5。HTTP 用户名和密码中的保留字符使用 URL 百分号编码；包含用户名或密码的 SOCKS 代理被配置校验拒绝。

控制面板支持直接代理 URL、变量名及 `${VARIABLE_NAME}` 引用，空值表示直接连接。直接 URL 保存于 `.env`，TOML 保存对应变量引用。历史 TOML 中的直接 URL 仍可读取，但账号编辑界面禁用该字段；转换为变量引用后可通过界面维护。

| 状态文件 | 内容 |
| --- | --- |
| `config.toml` | 账号启用状态及计划配置 |
| `data/accounts/<账号>/health.json` | 账号健康状态及验证结果 |
| `data/scheduler.json` | 调度器持久化状态 |

健康状态不覆盖账号启用配置。网络故障等临时状态在后续任务重新验证。`mcp.enabled = false` 仅拒绝新 MCP 服务启动；计划停用仅阻止新触发；GUI 服务停止取消其所属任务。
