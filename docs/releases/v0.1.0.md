# dyspark v0.1.0

首个公开版本，包含当前项目的账号管理、消息发送、每日计划和程序更新能力。

## 主要功能

- 通过浏览器控制面板管理多个抖音账号、代理、好友与群聊发送名单。
- 扫码登录、短信二次验证、独立浏览器登录状态和账号检查。
- 消息模板、每日定时发送、执行记录、重复发送保护与推送通知。
- CLI 和 MCP 接入；支持 Windows 原生、Linux 原生及 Docker 部署。
- 自动检查官方 `main` 分支的新提交，面板一键安装、重启与失败恢复。

## 本次修复

- 扩大绑定手机号提示的读取范围，覆盖扫码后选择短信方式及验证码表单切换。
- 号码读取与按钮、输入框定位分离，避免其他登录方式干扰短信操作。
- 将“刷新二维码”移到顶部“取消登录”旁，等待扫码时在小屏窗口内也可直接操作。
- 加固 Linux 重启后的进程锁识别，避免旧进程记录误判。
- 更新检查改用不包含文件差异的轻量接口，修复大提交响应被截断后检查失败的问题。

## 安装与更新

推荐通过 Git 克隆项目，按 [README](https://github.com/langbyyi/douyin-spark/blob/v0.1.0/README.md)
中的 Windows 或 Docker 步骤完成首次安装。Release 附件提供 Python wheel、源码分发包及 SHA-256 校验文件，
不包含配置、凭据和账号登录数据。

程序默认每 6 小时自动检查，安装由用户点击确认。更新源是官方 `main` 的完整提交编号，
不是 GitHub Release；今后推送到 `main` 的后续提交也会被检查到。

面板一键安装需要先停止原有服务并启用宿主更新管理器：

```bash
# 原生部署：使用项目对应的 Python（Linux / macOS 通常为 python3）
python deploy/update.py native

# Docker local：在宿主机执行；HTTPS 部署将 local 改为 spark
docker compose stop local
python3 deploy/update.py docker --service local
```

更新管理器以前台进程运行。普通 `spark gui` 或直接 `docker compose up` 启动的服务只提供检查，
需切换到管理器启动后才能一键安装。更新期间暂停新任务与配置修改，保留配置和抖音登录状态；
新版启动失败时尝试恢复旧版。完整参数与恢复方法见
[程序更新指南](https://github.com/langbyyi/douyin-spark/blob/v0.1.0/docs/updates.md)。
